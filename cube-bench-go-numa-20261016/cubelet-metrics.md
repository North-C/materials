# Cubelet 指标补充：十五轮前后快照

端点 `endpoint-redacted` 属于 **Cubelet，不是CubeMaster**。30份快照HELP/TYPE一致，十五轮process_start_time_seconds前后相同，所有counter差分非负且有效。没有额外采样。

GC HELP：`A summary of the wall-time pause (stop-the-world) duration in garbage collection cycles.`。TYPE=summary，sum差分是已记录STW暂停累计秒数，count差分是GC周期暂停观测数；不是并发GC全部CPU时间。

快照窗口覆盖正式创建、前后CLI和外围工作，不能将CPU增量除0.3–0.5秒正式耗时并称CPU利用率；也不能把指标差分完全归给100请求。内存、goroutines、threads只代表前后时点，不是peak。heap_inuse包含对象所在span未使用部分；go_threads的HELP为“Number of OS threads created.”，不等于本报告/proc完整线程采样。
