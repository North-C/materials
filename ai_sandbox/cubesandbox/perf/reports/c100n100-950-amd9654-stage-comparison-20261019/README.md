## 数据来源与比较边界

- **950**：用户确认即 `.90` 的2026-10-19独立PR4/warn抓取。直接引用已有 [stage-latency.csv](../v071-c100n100-pr4-agentwarn-unbound-20261019/analysis/stage-latency.csv)，详细配置见 [原报告](../v071-c100n100-pr4-agentwarn-unbound-20261019/REPORT.md)。API为正式100请求；主要组件统计母体为103个，含3次预热，归属为unknown_phase。
- **AMD 9654**：用户在会话中粘贴的formal阶段汇总，29行，其中23行有耗时，6行Master trace为空。归档 [所用字段摘录](amd9654-user-data.json)，只保存component、stage、count和五项耗时，以及共同的phase/owned信息；它不是完整原表或逐请求原始数据。未收到原始日志、runner/二进制身份、模板、CPU/NUMA、内核、缓存准备、运行日期和清理证据，未独立核验这些条件。
- AMD表明正式100个实例；部分阈值日志只覆盖子样本。例如network为AMD1/95023，cgroup为AMD3/95038，metadata为AMD2/95054，storage为AMD77/95066。CSV对应阶段已标出样本数，不应把这些条件均值当作全部实例均值。
- 此表展示观测值差异，**不是同条件硬件性能结论**。父子阶段、累计窗口和传播副本不能相加；不同样本群体的均值/分位数不能相减来补造阶段。沿用950源码核验过的流程树来对齐同名指标，不代表已核验AMD部署源码完全相同。
- API avg是单请求均值，不是整轮墙钟。AMD未提供整轮wall-clock，不能将其112.38444 ms与950抓取轮198.05185 ms直接对比；此表对齐的是两侧API单请求均值。

## 转换与验证

[DERIVATION.json](DERIVATION.json)记录输入路径、950来源commit/hash、逐行映射、phase和count。以component/stage为键，选择950的formal API与unknown_phase组件，以及AMD的formal行；每个指标依次写入950和AMD。共保留45条950来源指标和29条AMD输入记录；概念流程节点不生成耗时，AMD未提供的细分不通过同名/近似指标代填。没有重算统计量或四舍五入。

导出使用会话中的Spreadsheet artifact工具，离线逐格校验540个数值/空值位置。发布副本校验见 [SHA256SUMS](SHA256SUMS)：

```sh
shasum -a 256 -c SHA256SUMS
```
