## 先读的结论边界

- original 已含既有优化，不是“完全无补丁版本”；kit 不等于 stack，三类预写入也不是一个不断累加的补丁栈。
- 同一二进制可以有 off/on 两种有效配置；组件版本字符串相同不证明 SHA 相同。模板钉版本、运行开关和执行日志须分别核对。
- 旧盘 K2 的 kit+预写入 147.8 ms 与 original 165.2 ms 各10轮，但范围重叠；不能直接宣称稳定收益。
- hotset 的 160.868 对 178.150 ms 各五轮是不同模板配置对照；自动学习 prewrite 的 C2→D2 为同二进制/同模板开关对照，185.166→151.534 ms（18.16%），各五轮。二者不能合并或累加收益，受干扰/中止组另列。
- 上述均为特定条件的整轮耗时，不是单实例延迟。不同内核/模板/缓存/内存策略/启动器的数字不能组成跨批次排名。

## 可复核范围
